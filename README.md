# Conversor Livro Contábil

App para macOS que converte o CSV do Livro Contábil para o layout de importação de lote do Nasajon.

## Instalar

1. Baixe o instalador: **[ConversorLivroContabil.dmg](https://github.com/Arthurandradens/conversor-livro-contabil-releases/releases/latest/download/ConversorLivroContabil.dmg)**
2. Abra o arquivo e arraste o app para a pasta **Aplicativos**.
3. Na primeira vez, o macOS pede confirmação:
   - **macOS 14 ou anterior:** botão direito no app → **Abrir** → **Abrir**.
   - **macOS 15 ou mais novo:** tente abrir uma vez, depois vá em **Ajustes do Sistema → Privacidade e Segurança** e clique em **Abrir Mesmo Assim**.

Depois disso o app se atualiza sozinho.
